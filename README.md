# Evolution

Минималистичная **2D-игра-симуляция** о существе, которое учится на последствиях собственных действий и постепенно адаптируется к среде.

## Зафиксировано
- **Unity 6000.6.10f1 (Unity 6.6)**.
- Только 2D: камера, рендеринг, физика и геймплей.
- Существо строится из процедурной векторной геометрии.
- Морфология изменяется плавно и бесшовно: без внезапных замен спрайтов, скачков и разрывов контура.
- Существо запоминает последствия действий и использует опыт в дальнейших решениях.
- В мире есть препятствия, вода и погодные воздействия.
- Визуальная подача минималистична; постоянный тяжёлый HUD не нужен.

## Приоритет первого прототипа
Одно существо с замкнутой векторной формой, которая плавно меняется за счёт непрерывных параметров и имеет согласованную 2D-коллизию. Не начинаем с большой экосистемы, поколений, сложного ИИ и длинной документации.

## EV-CP1: интеграция подготовлена, Unity-валидация ожидается

Runtime-исходники и векторный shader интегрированы в **Assets/Evolution/EVCP1/**.
Откройте существующий корень репозитория строго в **Unity 6000.6.10f1**.
Полная инструкция, ручной чек-лист и ограничения: [UNITY_VALIDATION.md](docs/UNITY_VALIDATION.md).

Быстрый запуск новой демонстрации:
1. Создайте новую **Empty Scene**, без дополнительных камер/света.
2. Добавьте пустой GameObject и компонент **EvolutionPrototype2D**.
3. Оставьте **Use Keyboard Controls** выключенным и запустите Play локально: runtime
   создаст одну камеру, одно плавно меняющее форму существо и одно препятствие;
   существо движется вправо для проверки контакта.
4. Для отдельной проверки WASD/стрелок выйдите из Play, включите **Use Keyboard Controls**
   и проверьте legacy Input Manager/Both и фокус Game view.

Старое меню Tools → Evolution → Create Morphology Demo сохранено и запускает старую
реализацию; оно **не является** демонстрацией нового EV-CP1.
Новые .meta и сцену должен создать настоящий Editor; GUID вручную не задавались.
Только необходимый встроенный Physics 2D модуль добавлен в manifest; сторонних пакетов нет.

**Агент не запускал Unity, Play Mode или Unity Build.** Standalone CI не доказывает
компиляцию Unity API/shader или устойчивость контактов. Следующая игровая система
не начинается до вашей локальной проверки; обучение/адаптация/поколения не добавлены.
